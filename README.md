# Vertente

App de corrida pessoal: cada quilómetro que corres são 100 metros de altitude numa montanha sem cume.

- **Registar uma corrida:** print do Strava (a IA lê os números), ficheiro GPX ou à mão. Também dá para partilhar o print do Strava diretamente para a app, depois de instalada.
- **Perguntas rápidas:** esforço, como te sentiste, dores, sono e energia.
- **A Cabra Velha:** a IA da app, que te rebaixa para te puxar para cima. O tom é ajustável no Perfil.
- **Montanha:** o ecrã principal é o teu topo atual. Puxa para baixo para descer e ver as corridas anteriores.
- **Progresso:** quilómetros por semana, ritmo e recordes.

Os dados de cada pessoa ficam só no seu telemóvel. A IA usa o Gemini e, como reserva, o Groq, com a mesma chave das outras apps (Garfada, Forja, Nascente e Mirante) quando estão no mesmo aparelho.
